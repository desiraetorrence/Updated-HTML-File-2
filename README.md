# The Creative Showcase

## Project Overview

The Creative Showcase is a personal portfolio website created by Desirae Torrence for my Digital Media course. The website introduces who I am, highlights my creative projects, showcases my skills, and provides ways to connect with me. It was built using HTML, CSS, and JavaScript.

## Features

- Responsive layout for desktop and mobile
- Navigation menu with smooth scrolling
- About Me section with an interactive "Learn More About Me" button
- Featured Projects section
- Creative Skills section
- Contact section with links to email, Instagram, TikTok, and LinkedIn
- Back to Top link

## Technologies Used

- HTML5
- CSS3
- JavaScript
